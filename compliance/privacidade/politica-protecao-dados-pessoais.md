# Politica de Protecao de Dados Pessoais

**Documento:** POL-PRIV-002
**Versao:** 1.0
**Data de Vigencia:** Janeiro 2026
**Proxima Revisao:** Janeiro 2027
**Classificacao:** Interno

---

## 1. Objetivo

Estabelecer diretrizes internas para o tratamento de dados pessoais em conformidade com a Lei Geral de Protecao de Dados (LGPD - Lei 13.709/2018) e outras regulamentacoes aplicaveis, garantindo a privacidade e os direitos dos titulares de dados.

---

## 2. Escopo

Esta politica aplica-se a:
- Todos os colaboradores, estagiarios e terceiros
- Todos os processos que envolvam dados pessoais
- Dados de clientes, colaboradores, parceiros e fornecedores
- Dados em qualquer formato (digital ou fisico)

---

## 3. Definicoes

| Termo | Definicao |
|-------|-----------|
| **Dado Pessoal** | Informacao relacionada a pessoa natural identificada ou identificavel |
| **Dado Sensivel** | Origem racial, conviccao religiosa, opiniao politica, saude, vida sexual, dado genetico ou biometrico |
| **Titular** | Pessoa natural a quem se referem os dados |
| **Controlador** | Quem toma decisoes sobre o tratamento (Auricapri) |
| **Operador** | Quem trata dados em nome do controlador |
| **DPO/Encarregado** | Responsavel pela protecao de dados |
| **Tratamento** | Qualquer operacao com dados pessoais |

---

## 4. Principios do Tratamento

### 4.1 Principios LGPD

| Principio | Aplicacao |
|-----------|-----------|
| **Finalidade** | Tratar para propositos legitimos e informados |
| **Adequacao** | Tratamento compativel com as finalidades |
| **Necessidade** | Coletar apenas o minimo necessario |
| **Livre Acesso** | Facilitar consulta pelo titular |
| **Qualidade** | Manter dados exatos e atualizados |
| **Transparencia** | Informacoes claras sobre tratamento |
| **Seguranca** | Medidas tecnicas e administrativas |
| **Prevencao** | Prevenir danos aos titulares |
| **Nao Discriminacao** | Nao usar para fins discriminatorios |
| **Responsabilizacao** | Demonstrar conformidade |

---

## 5. Bases Legais para Tratamento

### 5.1 Bases Legais Utilizadas

| Base Legal | Quando Usar |
|------------|-------------|
| **Consentimento** | Marketing, cookies nao essenciais |
| **Contrato** | Prestacao de servicos contratados |
| **Obrigacao Legal** | Cumprimento de leis (fiscal, trabalhista) |
| **Interesse Legitimo** | Seguranca, prevencao a fraudes |
| **Protecao de Credito** | Analise de credito |

### 5.2 Registro de Bases Legais

Todo tratamento deve ter:
- Base legal documentada
- Finalidade especifica
- Prazo de retencao definido

## 6. Direitos dos Titulares

### 6.1 Direitos Garantidos

| Direito | Prazo de Atendimento |
|---------|---------------------|
| Confirmacao de tratamento | Imediato |
| Acesso aos dados | 15 dias |
| Correcao | 15 dias |
| Anonimizacao/bloqueio/eliminacao | 15 dias |
| Portabilidade | 15 dias |
| Informacao sobre compartilhamento | 15 dias |
| Revogacao de consentimento | Imediato |
| Oposicao | 15 dias |

### 6.2 Processo de Atendimento

1. Solicitacao recebida (email DPO, formulario, suporte)
2. Verificacao de identidade do solicitante
3. Registro da solicitacao
4. Analise e execucao
5. Resposta ao titular
6. Documentacao do atendimento

## 7. Inventario de Dados

### 7.1 Registro de Atividades de Tratamento

Manter registro contendo:
- Categorias de dados tratados
- Finalidades do tratamento
- Base legal aplicavel
- Categorias de titulares
- Compartilhamentos realizados
- Transferencias internacionais
- Prazos de retencao
- Medidas de seguranca

### 7.2 Atualizacao

- Revisao semestral obrigatoria
- Atualizacao a cada novo processo
- Aprovacao do DPO para mudancas

---

## 8. Dados Sensiveis

### 8.1 Tratamento de Dados Sensiveis

**Permitido apenas:**
- Com consentimento especifico e destacado
- Para cumprimento de obrigacao legal
- Para protecao da vida
- Para exercicio regular de direitos

### 8.2 Controles Adicionais

- Criptografia obrigatoria
- Acesso restrito (need-to-know)
- Log de todos os acessos
- Revisao trimestral de acessos

---

## 9. Retencao e Eliminacao

### 9.1 Tabela de Retencao

| Categoria | Prazo | Base Legal |
|-----------|-------|------------|
| Dados de clientes | Vigencia + 5 anos | Prescricao civil |
| Dados de transacao | 5 anos | Legislacao fiscal |
| Dados trabalhistas | 5-30 anos | CLT/Previdenciario |
| Dados de marketing | Ate revogacao | Consentimento |
| Logs de acesso | 6 meses | Seguranca |

### 9.2 Processo de Eliminacao

1. Identificacao de dados para eliminacao
2. Verificacao de obrigacoes legais de retencao
3. Aprovacao do DPO
4. Eliminacao segura (wipe, fragmentacao)
5. Certificado de eliminacao
6. Atualizacao do inventario

---

## 10. Compartilhamento de Dados

### 10.1 Requisitos para Compartilhamento

- Finalidade legitima e documentada
- Base legal adequada
- Informacao ao titular (quando exigido)
- Contrato com clausulas de protecao de dados

### 10.2 Due Diligence de Terceiros

Antes de compartilhar, verificar:
- Politicas de privacidade do parceiro
- Medidas de seguranca implementadas
- Historico de incidentes
- Conformidade com LGPD/GDPR

---

## 11. Transferencia Internacional

### 11.1 Mecanismos Autorizados

- Clausulas contratuais padrao
- Paises com nivel adequado de protecao
- Consentimento especifico do titular
- Garantias corporativas globais

### 11.2 Localizacao dos Dados

## 12. Privacidade desde a Concepcao (Privacy by Design)

### 12.1 Principios

- Privacidade como configuracao padrao
- Privacidade incorporada ao design
- Funcionalidade total sem comprometer privacidade
- Seguranca de ponta a ponta
- Visibilidade e transparencia
- Respeito pela privacidade do usuario

### 12.2 Aplicacao

**Novos projetos:**
- Avaliacao de impacto (DPIA) quando necessario
- Aprovacao do DPO antes do lancamento
- Minimizacao de dados na concepcao
- Controles de privacidade integrados

---

## 13. Avaliacao de Impacto (DPIA/RIPD)

### 13.1 Quando Realizar

- Tratamento em larga escala de dados sensiveis
- Monitoramento sistematico de areas publicas
- Decisoes automatizadas com efeitos legais
- Novos produtos/servicos com dados pessoais

### 13.2 Conteudo do DPIA

- Descricao do tratamento
- Avaliacao de necessidade e proporcionalidade
- Riscos aos direitos dos titulares
- Medidas para mitigar riscos
- Aprovacao do DPO

---

## 14. Incidentes de Dados

### 14.1 O que Reportar

- Vazamento de dados pessoais
- Acesso nao autorizado
- Perda de dados
- Alteracao indevida

### 14.2 Processo

1. Deteccao e reporte imediato ao DPO
2. Avaliacao de risco aos titulares
3. Contencao do incidente
4. Notificacao a ANPD (se aplicavel) - 72h
5. Notificacao aos titulares (se aplicavel)
6. Documentacao e licoes aprendidas

---

## 15. Responsabilidades

### 15.1 DPO (Encarregado)

- Orientar sobre conformidade
- Atender solicitacoes de titulares
- Comunicar com ANPD
- Realizar treinamentos
- Monitorar conformidade

### 15.2 Gestores

- Garantir conformidade da equipe
- Aprovar tratamentos em sua area
- Reportar incidentes

### 15.3 Colaboradores

- Seguir esta politica
- Tratar dados com cuidado
- Reportar incidentes e duvidas
