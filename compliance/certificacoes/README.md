## 3. Conformidade Atual

Embora nao possua certificacoes formais, a Auricapri mantem:

### 3.1 Seguranca da Informacao
- Politica de Seguranca da Informacao publicada
- Controles de acesso baseados em privilegio minimo
- Criptografia de dados em transito e repouso
- Procedimentos de resposta a incidentes
- Gestao de vulnerabilidades

### 3.2 Privacidade
- Conformidade com LGPD
- DPO designado (admin@auricapri.com.br)
- Politica de Privacidade publicada
- Procedimentos para direitos dos titulares
- Retencao e exclusao de dados documentados

### 3.3 Infraestrutura
- Hospedagem em provedores certificados:
  - **AWS:** SOC 1/2/3, ISO 27001, PCI-DSS
  - **Supabase:** SOC 2 Type II

## 5. Descricao das Certificacoes

### ISO 27001
Sistema de Gestao de Seguranca da Informacao (SGSI). Padrao internacional para gerenciamento de seguranca.

### ISO 27701
Extensao da ISO 27001 para privacidade. Sistema de Gestao de Informacoes de Privacidade (PIMS).

### SOC 2 Type II
Relatorio de controles de organizacao de servico. Avalia seguranca, disponibilidade, integridade de processamento, confidencialidade e privacidade.

### ePrivacy
Certificacao europeia de privacidade digital, focada em compliance com GDPR.

### PCI-DSS
Padrao de seguranca para empresas que processam pagamentos com cartao.
