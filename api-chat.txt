 Documentação da API - Mudanças

  POST /chat (Original - SEM mudanças)

  Aguarda resposta completa antes de retornar.

  Request:
  {
    "user_id": "whatsapp_123",
    "message": "quero um casaco",
    "weather": "frio"   // opcional
  }

  Response (JSON):
  {
    "status": "success",
    "message": "Claro! Temos um blazer...",
    "products": [...]
  }

  ---
  POST /chat/stream (NOVA)

  Streaming em tempo real via Server-Sent Events. A primeira palavra aparece em ~1-2s.

  Request (mesmo formato):
  {
    "user_id": "whatsapp_123",
    "message": "quero um casaco",
    "weather": "frio"
  }

  Response (Server-Sent Events):
  data: {"text": "Claro"}
  data: {"text": "! Temos"}
  data: {"text": " um blazer"}
  data: {"text": "..."}
  data: {"done": true, "products": [...]}

  ---
  Como consumir streaming

  JavaScript (fetch):
  const response = await fetch('/chat/stream', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({user_id: "123", message: "oi"})
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();

  while (true) {
    const {done, value} = await reader.read();
    if (done) break;

    const text = decoder.decode(value);
    const lines = text.split('\n');

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = JSON.parse(line.slice(6));
        if (data.text) {
          // Exibe chunk em tempo real
          console.log(data.text);
        }
        if (data.done) {
          // Streaming completo, produtos disponíveis
          console.log('Produtos:', data.products);
        }
      }
    }
  }

  curl:
  curl -N -X POST http://localhost:7001/chat/stream \
    -H "Content-Type: application/json" \
    -d '{"user_id": "test", "message": "oi"}'

  │ {"error": "..."}                    │ Erro no processamento         │
  └─────────────────────────────────────┴───────────────────────────────┘
